How to install

All projects are installed with HACS, the Home Assistant Community Store. Each project page has an Open in HACS button that opens the right repository in your own Home Assistant through My Home Assistant. If HACS cannot find a project by its name, add it as a custom repository; the steps are on each project page.

About Skylolerr

Skylolerr builds Home Assistant integrations for everyday problems at home and publishes them as open source. Every project comes with tests, translations into English, German, French and Italian, a light and dark theme, and a changelog for every release. Data is never dropped on an update: stored data is migrated, and Energy Flow Mapper keeps a backup before every change.

Found a bug or have an idea? Open an issue in the project's GitHub repository. Questions, translations and pull requests are welcome.
