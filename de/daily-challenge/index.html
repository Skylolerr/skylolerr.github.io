Daily Challenge

Zählbare Tagesziele, direkt in Home Assistant.

Daily Challenge verfolgt Mengen, die du jeden Tag erreichen willst: 20 Liegestütze, 30 Minuten lesen, 8 Gläser Wasser. Mit Streaks, Soll und Ist über die ganze Challenge, optionalem Aufholmodus und eigener Dashboard-Karte.

In HACS öffnen GitHub Neueste Version

Antippen, eintippen, aufholen

Dein Ziel, dein Streak, dein Dashboard

Ziel verfolgen

  • Eine Tagesmenge, keine Ja/Nein-GewohnheitJede Challenge hat ihr eigenes Tagesziel, ihre Einheit und ihre Knöpfe.
  • Soll und Ist über die ganze Laufzeit – Vorsprung oder Rückstand auf einen Blick.
  • Mit Enddatum: was noch fehlt, in wie vielen Tagen und wie viel du dafür im Schnitt pro Tag noch brauchst.
  • Jeden vergangenen Tag korrigieren mit den Aktionen.

Motiviert bleiben

  • Streaks mit wählbarer Regel – Tagesziel erreicht, oder irgendeine Menge.
  • Bester Streak, bester Tag, Durchschnitt pro Tag und Summen pro Woche, Monat und Jahr.
  • Optionaler AufholmodusEin verpasster Tag lässt sich am nächsten Tag nachholen, ohne den Streak zu verlieren.
  • Blueprint für ErinnerungenEine Meldung um 20:00, solange das heutige Ziel noch offen ist.

Passt in Home Assistant

  • Eigene Karte mit Fortschrittsring, Schnellknöpfen, Rückgängig, Streak sowie Soll und Ist, dazu ein visueller Editor – automatisch installiert und registriert.
  • Gewöhnliche Entitäten, die genauso mit Tile, Entities, Mushroom oder ApexCharts funktionieren.
  • Deutsch, Englisch, Französisch und Italienisch, helles und dunkles Design, dein Zahlenformat.

Die Karte ist dabei

Die Karte kommt mit der Integration und wird automatisch als Dashboard-Ressource registriert. Füge sie im Dashboard-Editor hinzu (Karte hinzufügen → Daily Challenge) und schalte jeden Teil im visuellen Editor ein oder aus, oder in YAML:

type: custom:daily-challenge-card
entity: number.push_ups_today   # eine beliebige Entität der Challenge
show_streak: true
show_target_vs_actual: true
show_remaining: true
show_required_average: true
show_catch_up: true
show_buttons: true

Nach dem Enddatum zeigt die Karte die Summe im Vergleich zum Endziel.

In vier Schritten installiert

Beta. Vor 1.0 sind Breaking Changes möglich. Sie stehen immer im Changelog, und deine erfassten Daten werden migriert, nie verworfen.

Voraussetzungen

  • Home Assistant 2026.10.0 oder neuer.
  • HACS für die Installation (oder eine manuelle Kopie, siehe unten).

Manuelle Installation: lade daily_challenge.zip aus der neuesten Version herunter, entpacke es nach config/custom_components/daily_challenge/ und starte Home Assistant neu.

  1. In HACS hinzufügen

    Klicke auf In HACS öffnen – My Home Assistant öffnet das Repository in deinem eigenen Home Assistant – und wähle Herunterladen.

    In HACS öffnen

    Oder füge es von Hand als benutzerdefiniertes Repository hinzu:

    1. Öffne HACS in der Seitenleiste.
    2. Öffne oben rechts das Menü ⋮ und wähle Benutzerdefinierte Repositories.
    3. Gib https://github.com/Skylolerr/ha-daily-challenge ein, wähle den Typ Integration und dann Hinzufügen.
    4. Suche in HACS nach Daily Challenge und wähle Herunterladen.

  2. Home Assistant neu starten

    Einstellungen → System → Ein/Aus-Knopf oben rechts → Home Assistant neu starten.

  3. Challenge anlegen

    Einstellungen → Geräte & Dienste → Integration hinzufügen → Daily Challenge, oder über den Knopf. Gib Namen, Einheit und Tagesziel ein. Jede Challenge ist ein eigener Eintrag; für eine weitere fügst du die Integration noch einmal hinzu.

    Daily Challenge einrichten

  4. Karte hinzufügen

    Dashboard bearbeiten → Karte hinzufügen → Daily Challenge.

Häufige Fragen

Nicht dabei? Eröffne ein Issue auf GitHub.

Wie verfolge ich ein Tagesziel wie Liegestütze oder Gläser Wasser in Home Assistant?

Installiere Daily Challenge, füge die Integration hinzu und gib einen Namen, eine Einheit und ein Tagesziel ein – zum Beispiel 20 Liegestütze. Leg die Karte Daily Challenge auf ein Dashboard und tippe +1, +5 oder +10, sobald du etwas geschafft hast. Die Karte zeigt den Fortschritt von heute, deinen Streak und ob du vor oder hinter deinem Soll liegst.

Ist Daily Challenge ein Habit-Tracker?

Daily Challenge zählt Mengen, keine Ja/Nein-Gewohnheiten. Jede Challenge hat ein Tagesziel und eine Einheit; sie zählt, wie viel du jeden Tag geschafft hast, summiert es über die ganze Challenge und vergleicht es mit dem Soll bis heute. Wenn du willst, zählt auch jede Menge über 0 für den Streak.

Was passiert mit meinem Streak, wenn ich einen Tag verpasse?

Ohne Aufholen beendet ein verpasster Tag den Streak. Im optionalen Aufholmodus kommt der Rückstand von gestern zum heutigen Ziel dazu; holst du ihn heute auf, zählt gestern trotzdem und der Streak bleibt. Nur gestern lässt sich retten, nichts Älteres.

Kann ich einen vergangenen Tag korrigieren?

Ja. Die Aktionen daily_challenge.set und daily_challenge.add haben ein optionales Datum, damit korrigierst du jeden Tag zwischen dem Startdatum und heute – zum Beispiel in den Entwicklerwerkzeugen oder in einer Automation.

Kann Home Assistant mich erinnern, wenn das Tagesziel noch offen ist?

Ja. Importiere den Blueprint für Erinnerungen: zu einer Zeit deiner Wahl, standardmässig 20:00, meldet er sich, solange das heutige Ziel noch offen ist. Die Nachricht kann enthalten, was noch fehlt.

Kann ich andere Karten wie Mushroom, Tile oder ApexCharts verwenden?

Ja. Jede Challenge legt gewöhnliche Entitäten an: eine Zahl für den heutigen Wert, Knöpfe für die Schritte und Sensoren für das heutige Ziel, den Fortschritt, die Summe, die Streaks, Vorsprung oder Rückstand und mehr. Sie funktionieren mit jeder Karte, in Automationen und im Verlauf.

Kann ich mehrere Challenges gleichzeitig verfolgen?

Ja. Jede Challenge ist ein eigener Eintrag: füge die Integration für die nächste einfach noch einmal hinzu. Jede bekommt ihr eigenes Gerät, ihre Entitäten und ihre Karte.

Wird um Mitternacht etwas zurückgesetzt, und was, wenn Home Assistant aus ist?

Nichts wird zurückgesetzt. Jeder Wert wird mit seinem Datum gespeichert, ein neuer Tag beginnt also einfach leer. Neustarts, die Zeitumstellung und ein ausgeschaltetes Home Assistant über Mitternacht sind kein Problem.

Welche Home-Assistant-Version braucht Daily Challenge?

Home Assistant 2026.10.0 oder neuer. Die Karte wird mit der Integration automatisch installiert und registriert.

Kann ich eine Obergrenze setzen, etwa höchstens ein Kaffee pro Tag?

Noch nicht. Daily Challenge kennt nur Mindestziele, und es gibt keine Ruhe- oder Pausentage: täglich heisst jeden Tag.
